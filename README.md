# [mascota_virtual]
## Descripción del Proyecto

Este proyecto consiste en una aplicación RPG de mascotas virtuales desarrollada con Spring Boot y MySQL. Los usuarios pueden crear y administrar mascotas, utilizar objetos, ganar experiencia, subir de nivel y utilizar objetos de su inventario  dentro de un sistema inspirado en videojuegos RPG.

El sistema implementa mecánicas de interacción entre usuario y mascotas, acciones y objetos, permitiendo modificar atributos como hambre, energía, felicidad y salud mediante el uso de ítems.

# Funcionalidades Implementadas

## Gestión de Usuarios
  - Registro de usuarios.
  - Asociación de mascotas a un usuario.
## Gestión de Mascotas
  - Crear mascota.
  - Visualizar información de la mascota.
  - Actualizar estado de la mascota.
  - Sistema de experiencia y niveles.
  - Sistema de tienda 
  - Visualizar todos los item del inventario
## Gestion de items 
  - Crear item y estadisticas 
  - Comprar items en tienda
  - Consumo de item en Mascota
  - Consumo de inventario al usar item
## Gestion de Inventario
  - Almacenamiento de item por usuario
  - Control de cantidad disponible

## La mascota posee atributos dinámicos:

 - Hambre,Energía,Felicidad,Salud
 - Uso de ítems sobre mascotas alteran el estado de mascota según el efecto del ítem.
 - Efectos asociados a cada ítem.
